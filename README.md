# Google Chat AI Replier – תגובות חכמות ל־Google Chat

סקריפט Tampermonkey שמוסיף ל־Google Chat ולצ'אט המובנה בתוך Gmail אפשרות ליצור תשובות אוטומטיות באמצעות Gemini AI.

הסקריפט מוסיף לסרגל הפעולות הקיים אייקוני SVG קומפקטיים ליצירת תשובת טקסט, תשובת אימוג'י, ניסוח מחדש, הגהה ופתיחת מסך ההגדרות. שמות הפעולות מוצגים בבועת מידע בעת ריחוף או מיקוד מקלדת.

הגרסה הנוכחית: **2.4.1**.

## מה חדש בגרסה 2.4.1

- תפריט הפעולות בחלון צר מוצג כעת בשכבה עליונה של הדף, ולכן אינו נחתך בתוך חלון הצ'אט הקטן של Gmail.
- מיקום התפריט מחושב מחדש בגלילה ובשינוי גודל, נפתח מעל הכפתור או מתחתיו לפי המקום הפנוי ונשאר תמיד בתוך גבולות החלון.
- נוספה פעולה ישירה **הגהה בלבד**: תיקון שגיאות כתיב והקלדה, רווחים ופיסוק בלי לשכתב, להחליף מילים או לשנות את הטון והמשמעות.
- תפריט החלון הצר מסודר כרשת קומפקטית ונגישה של שישה אייקונים.
- נוספה בדיקת ממשק שמדמה במפורש אזור פעולות עם `overflow: hidden`, בדומה לחלון הצ'אט הקטן ב־Gmail.

## מה חדש בגרסה 2.4.0

- כל כפתורי הסקריפט משתמשים באייקוני SVG ללא אימוג'י וללא מלל קבוע.
- לכל כפתור יש בועת מידע, `aria-label` ומצב מיקוד נגיש.
- הכפתורים משולבים בתוך סרגל הפעולות המקורי של Google Chat ומאמצים את הצבעים וההתנהגות החזותית שלו.
- ברוחב צר הפעולות מתקפלות אוטומטית לתפריט אייקונים קומפקטי כדי לא להתנגש בכפתורים קיימים.
- היסטוריית השיחה נבנית לפי הודעות ולא כטקסט גולמי, עם סימון מפורש של `אני` ו־`אחר`.
- זיהוי הודעות המשתמש מסתמך על הסימון המובנה של Google Chat (`data-is-viewer-message-creator`) ולא על ניחוש לפי שם.
- כאשר ההודעה האחרונה נכתבה על ידי המשתמש, Gemini מקבל הוראה להמשיך אותה או להתייחס להודעה קודמת של אדם אחר — ולא להשיב לה כאילו נכתבה בידי מישהו אחר.
- תגובה אוטומטית מופעלת רק כאשר ההודעה האחרונה שזוהתה נכתבה על ידי אדם אחר, וכל הודעה מטופלת פעם אחת בלבד.
- כפתור יצירת הניסוח החלופי שולח כעת גם את הטיוטה הקיימת ל־Gemini.

## 🚀 התקנה

### אפשרות ראשונה – התקנה ישירה מ־GitHub

1. התקינו את התוסף [Tampermonkey](https://www.tampermonkey.net/).
2. פתחו את קובץ הסקריפט ב־GitHub.
3. לחצו על הכפתור **Raw**.
4. Tampermonkey אמור לזהות את הסקריפט ולפתוח מסך התקנה.
5. לחצו על **Install**.

### אפשרות שנייה – התקנה ידנית

1. פתחו את לוח הבקרה של Tampermonkey.
2. לחצו על יצירת סקריפט חדש.
3. מחקו את התוכן הקיים.
4. העתיקו את כל תוכן קובץ הסקריפט מהמאגר.
5. הדביקו אותו בעורך.
6. שמרו באמצעות `Ctrl + S`.
7. רעננו את Gmail או את Google Chat.

## 🔑 יצירת מפתח Gemini API

הסקריפט משתמש ב־Gemini API לצורך יצירת התגובות.

1. היכנסו ל־[Google AI Studio](https://aistudio.google.com/app/apikey).
2. התחברו לחשבון Google.
3. צרו מפתח API חדש.
4. העתיקו את המפתח.
5. פתחו את Gmail או את Google Chat.
6. לחצו על אייקון ההגדרות שמופיע בסרגל הפעולות ליד שורת ההקלדה. בריחוף עליו תופיע הבועה **פתיחת הגדרות תגובות AI**.
7. הדביקו את המפתח בשדה **מפתח Gemini API**.
8. הזינו שם ובחרו מגדר.
9. לחצו על **שמירה**.

> אין לפרסם את מפתח ה־API ב־GitHub, בצילום מסך או בכל מקום ציבורי.

## 🛠️ שימוש

לאחר ההתקנה ורענון העמוד, יופיעו בסרגל הפעולות של שורת ההקלדה האייקונים הבאים. האייקונים אינם כוללים מלל קבוע; שם הפעולה מופיע בבועת מידע בעת ריחוף או מיקוד:

| אייקון | פעולה |
|---|---|
| בועת שיחה | יוצר תשובת טקסט בהתאם להקשר השיחה |
| פנים מחייכות | יוצר תגובה המורכבת מאימוג'י בלבד |
| חץ רענון | יוצר ניסוח חדש ושונה ומחליף את הטקסט הקיים |
| עיפרון | משפר את ניסוח הטיוטה הקיימת |
| שורות עם סימן אישור | מבצע הגהה בלבד: תיקון כתיב, הקלדה, רווחים ופיסוק בלי לשכתב |
| גלגל שיניים | פותח את מסך ההגדרות |

התגובה שנוצרת מוכנסת לשורת ההקלדה, כך שאפשר לבדוק ולערוך אותה לפני השליחה.

ברוחב חלון צר, שש הפעולות מתקפלות לכפתור שלוש נקודות. לחיצה עליו פותחת מעל הצ'אט תפריט קומפקטי עם אותם ששת אייקוני הפעולה; התפריט ממוקם אוטומטית כך שלא ייחתך גם בחלון Gmail קטן.

## זיהוי הדוברים וההקשר

ב־Google Chat כל הודעה נבדקת מול הסימון המובנה של הממשק שקובע אם בעל החשבון כתב אותה. לאחר מכן הסקריפט שולח ל־Gemini היסטוריה מובנית, לדוגמה:

```text
1. [אחר — דנה]
אפשר לעדכן מתי זה מוכן?

2. [אני — יעל]
כן, אני בודקת ואעדכן.
```

כאשר הרשומה האחרונה מסומנת כ־`אני`, התגובה החדשה תמשיך את דברי המשתמש או תתייחס להודעה הרלוונטית האחרונה שסומנה כ־`אחר`. תגובה אוטומטית לא תישלח בעקבות הודעה שסומנה כ־`אני`.
